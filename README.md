# Smart-Travel-Planner-Website
Smart Travel Planner is an intelligent trip planning and budget management platform that simplifies travel with personalized itineraries, destination recommendations, budget estimation, expense tracking, real-time weather updates, and interactive maps with route planning.BuiltwithHTML,CSS,JavaScript and Firebase, featuring a modern,responsiveUI/UX.
# 🌍 Smart Travel Planner – Plan Smarter, Travel Better!

**Smart Travel Planner** is an intelligent trip planning and budget management web application designed to simplify the travel planning experience. It helps travelers discover destinations, generate personalized itineraries, estimate trip expenses, manage budgets, and explore travel routes through a single, user-friendly platform.

The platform aims to make travel planning smarter, easier, more organized, and budget-friendly.

---

## 🚀 Features

### 🔐 1. User Authentication
- Secure user registration and login.
- Firebase Authentication integration.
- Google Sign-In support.
- Personalized user dashboard.

### 🗺️ 2. Smart Trip Planning
- Plan trips based on destination and travel dates.
- Personalized day-wise travel itineraries.
- Travel preferences and activity recommendations.
- Suggested destinations and attractions.
- Save and manage planned trips.

### 💰 3. Budget Management
- Estimate total trip expenses.
- Manage transportation, accommodation, food, and activity costs.
- Track daily expenses.
- Monitor remaining budget.
- Visualize spending through charts.
- Currency support using Indian Rupees (INR ₹).

### 🌤️ 4. Weather Updates
- Current weather information.
- Temperature, humidity, and wind speed.
- Multi-day weather forecasts.
- Weather-based travel planning assistance.

### 📍 5. Interactive Maps & Route Planning
- Explore destinations through interactive maps.
- Display travel locations and markers.
- Visualize routes between destinations.
- View estimated travel distances and journey information.

### 📱 6. Modern UI/UX
- Responsive design for desktop, tablet, and mobile.
- Modern travel-themed interface.
- Interactive cards and navigation.
- Smooth animations and user-friendly layouts.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd Smart-Travel-Planner-Website
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file using the provided `.env.example` file and add the required Firebase and API configurations.

**5. Start the development server**

```bash
npm run dev
```

**6. Open in your browser**

```text
http://localhost:5173
```

## 🔥 Firebase Configuration

The application uses Firebase services for authentication and data management.

To configure Firebase:

1. Create a project in Firebase Console.
2. Enable Email/Password Authentication.
3. Enable Google Authentication if required.
4. Create a Cloud Firestore database.
5. Configure the Firebase credentials.
6. Apply appropriate Firestore security rules.

Firebase configuration and API integrations must be completed before using their respective features.
